> **Nesta área:** ferramentas de reprodução e verificação, executadas a partir da raiz conforme as dependências do projeto.

`verificar_colab_recuperado.py` executa o núcleo original recuperado em planilha sintética temporária e confere XLSX/CSV. `executar_notebooks.py` executa o notebook novo via nbclient e valida o esquema do acervo histórico.

Execute a partir da raiz. Os scripts usam caminhos relativos à localização do projeto. Saídas são gravadas em build/, com falha por código não zero.
