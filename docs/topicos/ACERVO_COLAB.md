# Guia do acervo Colab

O notebook recuperado é uma referência histórica de implementação. Os módulos novos de auditoria são outra camada: conservam campos raw e acrescentam representação NFC e alertas. Uma camada não substitui a outra.

**Para estudar:** acompanhe o caminho da primeira coluna original até a nova coluna de grafia proposta; identifique onde valores e estilos são copiados. Depois use o fixture sintético para demonstrar que a coluna original não foi sobrescrita.

**Critério observável:** explicar qual saída é uma transformação do programa e qual afirmação exigiria cotejo linguístico independente.
